# Unity Feature Planning

1. Clarify expected behavior and constraints.
2. Inspect relevant scripts, scenes, prefabs, packages, and existing conventions.
3. Identify interfaces and dependencies before splitting work.
4. Assign a single owner to each file that must change.
5. List failure cases, lifecycle concerns, and integration risks.
6. Define acceptance criteria and tests.
7. Return a plan for review before implementation.
8. Do not modify files during planning.
