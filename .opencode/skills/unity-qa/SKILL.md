# Unity QA

1. Derive tests from the acceptance criteria.
2. Include normal cases, boundaries, invalid state, and regression scenarios.
3. Specify setup, action, expected result, and evidence.
4. Check available automated test results and logs.
5. Clearly mark tests not executed.
6. Identify what still requires Unity Editor or Play Mode verification.
7. Do not change project files.
